# Simple Scripts

Just a bunch of simple scripts just for fun.

## Repository layout

- `python/games/` contains interactive games.
- `python/utils/` contains reusable and task-focused utilities.
- `python/exercises/` contains learning exercises grouped by subject.
- `python/tests/` contains automated tests.

See [`python/README.md`](python/README.md) for the complete script catalog.

## Python utilities

Run the password generator from the repository root:

```sh
python3 python/utils/password_generator.py
```

Run the Python test suite:

```sh
python3 -m unittest discover -s python/tests -v
```
