# Progressive hints

Try the example suite before opening a hint.

<details>
<summary>Hint 1</summary>

A hash map locates keys quickly, but you also need a recency order.

</details>

<details>
<summary>Hint 2</summary>

Successful reads and all writes move a key to the most-recent end.

</details>

<details>
<summary>Hint 3</summary>

Combine a map with a doubly linked list, or use a suitable ordered container.

</details>
